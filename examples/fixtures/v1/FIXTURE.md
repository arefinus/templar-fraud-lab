# Fixture v1

Authored synthetic demonstration data. Fictional identifiers. Not derived from any person, company, account or dataset. Generated by `tools/make_fixture.py` seed `42`, version v1.

Rows: 6000. Columns: see `fixture_meta.json`. Label `is_fraud` is drawn from a hand-written logistic model over amount, country mismatch, velocity, device type, IP risk, account age and merchant category, with Gaussian noise, so the structure is learnable but not trivially separable. The final 8% of the timeline introduces a merchant category absent earlier and a few very large amounts to exercise unknown-category and out-of-range handling on the test slice.
